# Archive

이 폴더는 현재 실행 경로에서 분리했지만 아직 삭제하지 않은 자료입니다.

## Contents

- `contracts/AGENTS_ORIGINAL_BACKUP.md`: 현재 계약 이전의 원본 백업
- `outputs/legacy`: 과거 수동 재생, 역설계, 구형 엔진, 모델 재현 실험, 무효 결과, 복구 자료

## Rules

- archive 자료는 현재 전략 권한이 아닙니다.
- 새 코드가 archive 경로를 기본 입력으로 참조하면 안 됩니다.
- 다시 사용하려면 목적, 생성 코드, 기간, 미래 데이터 여부, 계약 버전을 먼저 감사합니다.
- 감사된 자료는 archive에서 직접 수정하지 않고 현재 `output`으로 복사해 새 버전으로 만듭니다.
- 삭제는 중복 파일과 재현 가능 여부를 확인한 뒤 별도 승인으로 진행합니다.

과거 산출물 이름은 검색 가능성을 위해 그대로 보존했습니다. 내부 문서에 기록된 옛 `output/...` 경로는 현재 `archive/outputs/legacy/...`를 가리킬 수 있습니다.
