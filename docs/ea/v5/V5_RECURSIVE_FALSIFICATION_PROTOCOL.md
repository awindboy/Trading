# V5 Recursive Falsification Protocol

Status: `MANDATORY V5 RESEARCH GOVERNANCE`
Date: `2026-08-27`

Purpose: counter the failure mode where a plausible first explanation becomes the default truth and every later
observation is interpreted through it.

## Required checkpoint before every major interpretation

Write answers to all eight questions:

1. **Current thesis** — what do I currently think is happening?
2. **Opposite thesis** — if the opposite were true, what would I observe?
3. **Simpler alternative** — can trend, volatility, time-of-day, selection, or costs explain the result without the mechanism?
4. **Prior-project recurrence** — did V1-V4 already produce a similar apparent relationship that later failed?
5. **Placebo / negative control** — what should look similar if the proposed object is not special?
6. **Causal boundary** — which quantities were truly available at the proposed decision time?
7. **Geometry / economics** — does waiting for confirmation consume the remaining payoff?
8. **Kill condition** — what result forces downgrade/closure rather than another threshold?

## Required checkpoint after a promising result

Before writing `SUPPORTED`, ask:

- Did pooled significance survive market/year/direction decomposition?
- Did it survive an outcome-blind placebo?
- Did it survive causal pre-state matching or other obvious confounder control?
- Is a tail mean being mistaken for a high-probability effect?
- Does the effect predict **direction**, or only volatility/intensity?
- Does a later confirmation add new future information, or merely describe a move that already happened?
- Is a successful-trader quote being used as evidence rather than as a hypothesis source?
- Would the conclusion remain the same if the most favorable market/year were removed?

## Status vocabulary

Use one of:

```text
SUPPORTED ENOUGH TO PREREGISTER A CANDIDATE
OBSERVABLE PROXY INSUFFICIENT
MECHANISM NOT SUPPORTED
CONFOUNDED / RESEARCH DESIGN INSUFFICIENT
```

Do not use `promising` as a substitute for a status.

## No rescue rule

If a result fails a frozen control:
- record the failure;
- consume the discovery;
- return to the mechanism/source corpus;
- define the next hypothesis before viewing its outcomes.

Do not add an exception merely because it restores the desired direction.
