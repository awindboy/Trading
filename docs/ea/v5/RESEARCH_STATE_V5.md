## First synthesis

The corpus does not support a universal chart pattern.

It supports a hierarchy:

```text
market state
-> location/boundary
-> approach character
-> interaction
-> response
-> path / available room
-> invalidation
-> payoff / lifecycle
```

The strongest first empirical object is `boundary interaction`, especially breakout success vs failure.

## Evidence status

### Strong empirical/mechanistic support
- trend persistence exists across many futures/forwards and long histories;
- stop-loss/take-profit orders can cluster around technical levels;
- price impact is strongly related to order-flow imbalance and depth.

### Practitioner-supported but requires project validation
- contraction -> expansion as a tradeable state transition;
- wave "character";
- effort/result as a chart-level exhaustion/absorption clue;
- exact breakout/retest geometry;
- which boundaries matter for our markets/horizon.

### Explicitly unresolved
- whether MT5 tick volume is sufficient for an effort/result proxy;
- whether a GOLD-specific semantic state transfers;
- whether V5 can satisfy final >=50% WR while preserving >1R winners;
- whether learned models add value after mechanism primitives are available.
