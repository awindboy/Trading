# V12 compact results and receipts

There is no V12 performance result yet.

The retained inception artifacts are architecture, source, causal-observation,
engineering, and schema contracts. They do not prove candidate quality,
profitability, stop reduction, Python/MQL5 parity, or production readiness.

Future compact receipts belong here only when they name:

- the exact contract and code revision;
- source hashes and evidence window;
- consumed versus untouched chronology;
- candidate and ambiguity counts;
- complete stop/right-tail/exposure scorecard;
- parity and contamination status;
- conclusion, rejected interpretations, and authority boundary.

Large event ledgers, model files, fold predictions, tester reports, and renders
remain under ignored `output/`.
