## Architectural correction
This child does NOT start from the 620 `m1_direct_transfer` population and then ask whether an indicator agrees with the event direction.

Direction authority is moved earlier:
1. at atomic M1 sweep/recovery time, compute a causal indicator prior from completed HTF bars;
2. prior declares LONG / SHORT / NEUTRAL before the later M5 ownership transition;
3. local sweep/recovery + M5 transition is timing/geometry confirmation only;
4. a local transition opposite the prior is a counter-prior correction and is not traded in this child;
5. `m1_direct_transfer` is NOT required. This lets the direction layer potentially recover opportunities previously excluded by V3 directional microstructure.
