## Fail-closed rules

Stop before outcomes if:
- broad event parity is wrong;
- context timestamps use future bars;
- B and C do not have equal dimensionality/model configuration;
- prior implementation cannot be identified and the new implementation has not been frozen;
- target definition differs across arms.
