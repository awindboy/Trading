# V6 Decisions

Date initialized: `2026-08-28`

## V6-D001 — Clean generation boundary

V5 is closed. The event-conditioned AI/generalization direction is named V6.
This avoids mixing incomplete V5 external-state research with the new mandate.

## V6-D002 — GOLD remains primary

GOLD remains the primary discovery market.
Market expansion is a later generalization stage, not a reason to abandon accumulated GOLD research.

## V6-D003 — V3 validation collapse is a design constraint

Any V6 result that succeeds only in one period but reverses in another is a failure of generalization, even if pooled performance is attractive.

## V6-D004 — V4 no-learning is a design constraint

V6 must establish stable information before escalating model complexity.
No `newer model = new hypothesis` reasoning.

## V6-D005 — Event-conditioned formulation

Initial learning conditions on the exact broad V3 event population rather than predicting every market timestamp.
V3's later selection gates are not inputs or population filters.

## V6-D006 — Same-capacity placebo is mandatory

Cross-market context claims must beat a same-dimensionality input with no new information.
For V6-001A this control is exact `GOLDx3` block duplication.

## V6-D007 — Adaptation remains locked

Online/test-time adaptation may be researched only after static context information is classified and only with strictly causal past information.

## V6-D008 — 2022 and 2021 handling

GOLD 2022 is consumed V3 validation and may only falsify a frozen V6 pipeline.
GOLD# 2021 remains untouched.
