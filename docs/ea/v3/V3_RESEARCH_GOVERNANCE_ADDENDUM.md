# V3 Research Governance Addendum — Escalation / Ceiling Rule

Status: `ACTIVE`
Date: `2026-08-25`

## Principle

V3 is not required to save the current strategy.

The objective is to find a real, reproducible GOLD edge.

When many natural variants of one idea fail to improve robustness, stop refining the same
idea and question a higher-level assumption.

## Escalation ladder

```text
L1 — component
    swing detector
    FVG selection
    Entry depth
    local timing

L2 — architecture
    source/trigger scale
    continuation vs reversal
    liquidity lifecycle
    invalidation model
    state-specific strategy module

L3 — fundamental
    is the proposed event causal?
    does direction information exist before Entry?
    is one strategy valid across all GOLD states?
    is price-only information sufficient for the objective?
```

A research line can be classified:

```text
ACTIVE
PROMISING
STRUCTURAL_CEILING_SUSPECTED
REJECTED
DEFERRED
```

## Naive-control requirement

A complicated ICT/mentor-inspired mechanism must outperform a simpler causal control.

Otherwise the complex terminology does not receive strategy authority.

## No sunk-cost defense

Time already spent on an architecture is not evidence for keeping it.

Negative evidence and falsification are permanent project assets.
