## Decision V9-043 — Consumed memory alone has no continuation-entry authority

P004 archaeology showed that a consumed CP can still be followed by sharp reversal and nearby higher memory.

Therefore:

```text
memory consumed != automatic re-entry
```

A continuation trade requires a newly earned anchor and actual route room.

## Decision V9-044 — No known destination is no longer an automatic veto

The old simplification:

```text
no known destination -> NO TRADE
```

is downgraded.

Introduce a descriptive research state:

```text
OPEN ROUTE / PRICE DISCOVERY
```

when the last meaningful directional memory is consumed and a full causal-history check finds no meaningful downstream active memory.

## Decision V9-045 — Price discovery is not automatic trade authority

Open route requires a nearby **thesis-dependent** counterfactual anchor.

Do not chase breakout price merely because the route is open.

Do not manufacture a tiny pullback anchor if losing it would not actually falsify the larger open-route thesis.
