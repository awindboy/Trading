# V9 Research Pivot — Market Flow Atlas

Date: `2026-09-11`
Status: `CONSUMED-DATA RESEARCH NOTE`

## Trigger for the pivot

Jan-Feb development exposed a recurring failure pattern:

```text
loss / low frequency
-> diagnose one local weakness
-> change POI / trigger / trailing
-> new weakness appears
```

Increasing H1 opportunity frequency and improving M5 retracement execution did not by themselves produce a stable strategy.

This resembles the V3-to-V9 risk of optimizing local mechanics before the strategy's market model is understood.

## Decision

Pause local trade optimization.

Use already-consumed chart history as an answer sheet and map the full continuous sequence:

```text
reaction / arrival
-> price delivery
-> reaction / arrival
-> ...
```

Research price as:

- migration;
- repair;
- balance;
- compression;
- expansion;
- false break;
- liquidity raid;
- POI response/failure;
- state transition.

## Analytical stance

Do not expect raw OHLC alone to reveal one universal rule.

Use a toolkit:

- deterministic ICT object geometry;
- POI / OB / FVG / liquidity relationships;
- displacement / acceptance / rejection;
- volatility and range context;
- MACD / Bollinger / MA / momentum lenses where useful.

A tool stays only if it repeatedly clarifies many flows.

## Goal

Produce the smallest reusable market-flow grammar that explains a meaningful share of diverse consumed periods while keeping counterexamples visible.

Then reverse-engineer the tradable subset and return to causal replay.

No July data is authorized by this pivot.
