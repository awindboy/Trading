## 4. Strategic lesson carried forward

March corrected the false equivalence:

```text
scale alignment
!=
Child stop must equal Parent death
```

The usable hierarchy became:

```text
Parent Journey = larger H1/H4 working context
Child = a distinct local attempt inside or against that context
Hard/local risk = where this Child is wrong
```

A stopped Child may be followed by another attempt if the market supplies causally distinguishable new information. There is no N-attempt rule and no requirement that the next Child wait a fixed time or complete a fixed pattern.

March also reinforced the strategy's desired convex behavior: several bounded failures can coexist with a much larger winner when the Parent Journey actually develops.
