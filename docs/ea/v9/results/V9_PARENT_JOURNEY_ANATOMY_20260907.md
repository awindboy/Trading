## 1. Purpose

This study does not define a trend algorithm and does not attempt to label every swing correctly.

Question:

> When a human sees a large H1/H4 directional journey, where were the V9 local memories, nodes, entries and exits located inside that larger journey, and why did V9 capture only small local bridges?

The segmentation below is deliberately outcome-informed archaeology. Start/end anchors are descriptive landmarks chosen to understand scale and role, not frozen detection rules.

## 2. Main result

The previous V9 replay was primarily a **local-corridor trader**, not a parent-journey trader.

It was comparatively good at:

- finding close local falsification;
- avoiding late child entries;
- waiting for failed repair;
- respecting genuine invalidation.

But it repeatedly treated local child memories as if they were sufficient to terminate the whole trading opportunity.

The consequence was:

```text
good execution location
+
small child destination
=
high local R
but very small fraction of the H1/H4 journey
```

The missing object is a persistent **Parent Journey State**.

## 5. Scale hierarchy correction

The old V9 vocabulary contained parent/child structure, but trading behavior did not fully respect the hierarchy.

Required separation:

### Parent Journey
H1/H4-scale directional market campaign currently capable of continuing after child damage.

Question:
- What broad route is still controlling settlement/value migration?
- What evidence would show that the opposing route has actually taken control?

### Child Route
M15/H1 bridge or pullback inside the parent journey.

Question:
- Is the current child advancing, repairing, failing, or rotating?

### Execution Structure
M5/M15 local structure used to obtain a close falsification.

Question:
- Can a trade be entered here such that the current local thesis becomes wrong nearby?

The layers should interact as:

```text
Parent Journey
    |
    +--> determines strategic continuity / campaign context
            |
            v
Child Route
    |
    +--> determines current bridge and local role
            |
            v
Execution Structure
    |
    +--> determines precise entry and local invalidation
```

Do not force all three to share one stop, one target, or one timeframe.

## 6. What a parent journey is NOT

Do not turn this study into:

- exact HH/HL rules;
- moving-average trend labels;
- N-bar trend thresholds;
- fixed ATR pullback limits;
- a requirement to predict the final top/bottom.

A parent journey is a working causal hypothesis, not an objective regime label.

The useful question is:

> After meaningful counterflow, does the market repair and re-establish the prior route, or has opposing value migration become the more coherent route?

This promotes existing V9 principles to a higher scale:

```text
reaction != rejection
child break != parent failure
repair / failed repair matters at every scale
Role > Pattern
```

## 7. New interpretation of memory

Not every memory encountered inside a parent journey should have the same exit authority.

Working roles:

```text
PARENT ORIGIN / PARENT FAILURE AREA
PARENT DESTINATION / MAJOR ARRIVAL
CHILD TRANSIT MEMORY
CHILD ORIGIN
EXECUTION ANCHOR
```

A child transit memory can:
- cause reaction;
- produce a local bridge exit;
- be consumed;
- become support/resistance for the next child route;

without ending the parent journey.

The research problem is not to name every node perfectly.

It is to stop treating every nearest memory as if it had equal strategic authority.

## 8. Campaign interpretation

A large trend does not require one heroic entry held from bottom to top.

More natural V9 extension:

```text
Parent Journey stays active
    |
    +--> execution opportunity A -> local trade resolves
    |
    +--> parent survives
    |
    +--> execution opportunity B -> local trade resolves
    |
    +--> parent survives
    |
    +--> execution opportunity C
    |
    +--> parent actually switches / dies
```

This preserves:
- close local invalidation;
- no hindsight rescue;
- no passive runner requirement;

while allowing the strategy to economically participate in a 5S-20S parent journey.

## 9. Research implications

### Retain
- original local Decision Corridor entry logic as useful execution architecture;
- thesis-based invalidation;
- no rescue after trade invalidation;
- H4 ATR as scale coordinate, not structure;
- OPEN ROUTE research;
- sequential continuation.

### Correct
- a resolved local trade must not automatically reset parent journey understanding;
- a nearby child memory is not automatically a parent destination;
- parent context must change actual trading ambition/re-entry behavior or it is merely narrative.

### New primary question

> Can V9 maintain a causally honest Parent Journey hypothesis across multiple child trades without turning it into a rigid trend classifier or hindsight narrative?

## 10. Immediate next study

Do not design a trend algorithm.

Perform future-hidden replay with a **two-level journal**:

### Parent ledger
Record only when parent understanding materially changes:
- parent journey working hypothesis;
- evidence supporting continuation;
- strongest meaningful damage;
- what would make the parent story less coherent;
- whether parent is alive / damaged / unresolved / switched.

These are trader beliefs, not objective market labels.

### Trade ledger
For every child trade:
- entry;
- local falsification;
- first child checkpoint;
- result;
- whether the parent story changed.

Critical rule:

```text
trade loss may reset the child
but must not silently reset the parent
```

and:

```text
parent damage may remain unresolved
without forcing reversal prediction
```

Seek:
- parent continues after losing local trade;
- parent dies after winning local trade;
- large pullback that repairs;
- apparent open route that fails;
- sequential re-entry that loses;
- cases where no coherent parent journey can be stated.

Only after this discretionary language survives counterexamples should formalization begin.
