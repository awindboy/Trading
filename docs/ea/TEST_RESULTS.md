# EA Test Results

No baseline EA Strategy Tester results yet.

## Required reporting format

For every significant test record:

- EA version / commit
- symbol
- broker
- period
- tester model
- warm-up period
- trading period
- spread / commission assumptions
- number of trades
- win / loss
- profit factor
- expectancy in R
- max drawdown if available
- protocol violations
- known implementation defects

Profitability results are invalid if known protocol violations remain.
