# 영상 심층 분석

[원본 영상 바로가기](https://www.youtube.com/watch?v=v2d-oOuu03s) · 16:50 · 21/21

> **한 문장 결론:** 외부 상승 안에서도 내부 하락 rotation을 별도 거래할 수 있으며, 유동성은 단일 pivot이 아니라 횡보 경계·추세선·반복 방어로 참가자 손절이 집중된 이유를 종합해 판단한다.

## 이 영상이 전체 강의에서 맡는 역할
외부와 내부 시나리오를 동시에 읽는 실전 종합편이다. 방향 하나만 고집하지 않되 서로 다른 구조 범위의 TP와 무효화를 섞지 않는 것이 핵심이다.

## 스승님의 판단 순서
1. 횡보 경계와 반복 방어에서 포지션 군집과 손절 위치를 찾는다.
2. 그 유동성 근처의 원인 OB를 확인한다.
3. 현재 활성 내부 trend와 외부 trend를 따로 표시한다.
4. 내부 short라면 내부 목적지와 trigger를 사용한다.
5. 내부 하락 종료 뒤 외부 상승 continuation 조건을 다시 확인한다.

## 실제 차트에 적용할 규칙
- 유동성마다 pivot 모양이 아니라 참가자가 손절을 둘 이유를 적는다.
- 외부·내부 시나리오의 보호점과 목적지를 별도 관리한다.
- 내부 시나리오 종료를 외부 trend reversal로 확대하지 않는다.

## 잘못 적용하기 쉬운 부분
- 한 차트에는 하나의 trend만 존재한다고 가정하는 것
- 횡보의 모든 고저점을 같은 유동성으로 표시하는 것
- 내부 short가 맞았다는 이유로 외부 상승 map까지 삭제하는 것

- 내 TP와 보호점이 같은 구조 범위에 속하는가?
