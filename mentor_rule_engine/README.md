# Mentor Rule Engine

이 패키지는 `mentor_engine`의 구조 분석을 사용했던 과거 규칙 기반 연구 엔진입니다.

- 현재 Mentor AI Replay V4의 실행 엔진이 아닙니다.
- `run_mentor_blind_week_v5.py`, `run_mentor_scenario_discovery_v6.py`, `run_mentor_scenario_discovery_v7.py` 등의 레거시 연구에서 사용합니다.
- 현재 거래 권한은 루트 `AGENTS.md`와 V4 파이프라인에 있습니다.

이 패키지를 수정하거나 재사용할 때는 과거 결과를 현재 V4 성과와 혼합하지 않습니다.
